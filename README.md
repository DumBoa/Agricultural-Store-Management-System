# Agricultural Store Management System

## Overview

The **Agricultural Store Management System** is a comprehensive web application built with **Django** to help manage the daily operations of an agricultural retail store. It provides modules for inventory management, point-of-sale (POS), customer loyalty, promotions, suppliers, employee management, and business reporting.

The system is designed with scalability and maintainability in mind, making it suitable for small and medium-sized businesses.

# Technologies

* **Language:** Python 3.10+
* **Framework:** Django 4.2.x
* **API:** Django REST Framework
* **Database:** SQLite (can be upgraded to MySQL or PostgreSQL)
* **Frontend:** Tailwind CSS, HTML, JavaScript
* **Version Control:** Git & GitHub

# Features

## Dashboard

* Business overview
* Revenue statistics
* Inventory alerts
* KPI summary
* Sales charts

## Point of Sale (POS)

* Fast checkout
* Shopping cart
* QR/Barcode scanning
* VAT calculation
* Cash payment
* VNPay integration

## Customer Management

* Customer profiles
* Search & filtering
* Loyalty points
* Reward redemption
* Excel export

## Product Management

* Product categories
* Units of measurement
* Pricing
* Barcode & QR code support
* Product images

## Inventory Management

* Batch management
* Expiration date tracking
* Stock-in / Stock-out
* Inventory checking
* Stock monitoring

## Promotion Management

* Discount vouchers
* Promotional campaigns
* Combo offers

## Supplier Management

* Supplier information
* Supplier evaluation
* Price comparison

## Employee Management

* Employee profiles
* Work shift management

## Reports

* Revenue reports
* Inventory reports
* Debt reports
* Export to Excel and CSV
